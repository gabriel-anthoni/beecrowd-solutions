    <td valign="top">
      <b>📥 Entrada:</b><br>
      A entrada contém um valor de ponto flutuante (dupla precisão - <code>double</code>), correspondente ao raio <code>R</code> do círculo.<br><br>
      <b>🧠 Lógica:</b><br>
      • A fórmula para calcular a área de um círculo é <code>A = π · R²</code>.<br>
      • O enunciado especifica o valor fixo de <code>π = 3.14159</code>.<br>
      • Ler o valor do raio <code>raio</code> da entrada padrão.<br>
      • Efetuar o cálculo multiplicando <code>π</code> pelo quadrado do raio (<code>raio * raio</code>).<br>
      • Imprimir o resultado com a mensagem <code>A=</code> e o valor formatado exatamente com <b>4 casas decimais</b> após o ponto, seguido de uma quebra de linha.<br><br>
      <b>📤 Saída:</b><br>
      Imprima a mensagem <code>A=</code> seguida pelo valor da variável <code>A</code> com 4 casas decimais e uma quebra de linha.
    </td>
    <td valign="top">
      <b>📥 Input:</b><br>
      The input contains a floating-point value (double precision), representing the circle's radius <code>R</code>.<br><br>
      <b>🧠 Logic:</b><br>
      • The formula to calculate the area of a circle is <code>A = π · R²</code>.<br>
      • The problem specifies the exact value for <code>π = 3.14159</code>.<br>
      • Read the radius value <code>raio</code> from standard input.<br>
      • Compute the area by multiplying <code>π</code> by the square of the radius (<code>raio * raio</code>).<br>
      • Print the message <code>A=</code> followed by the result formatted to <b>4 decimal places</b> and an end-of-line break.<br><br>
      <b>📤 Output:</b><br>
      Print the message <code>A=</code> followed by the value of variable <code>A</code> formatted with 4 decimal places and a newline.
    </td>
  </tr>
