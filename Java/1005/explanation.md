### 📌 Resumo / Overview

<table align="center" width="100%">
  <tr>
    <th width="50%">🇧🇷 Português (PT-BR)</th>
    <th width="50%">🇺🇸 English (EN)</th>

  <tr>
    <td valign="top">
      <b>📥 Entrada:</b><br>
      A entrada contém dois valores de ponto flutuante de dupla precisão (<code>double</code>), correspondentes às notas de um aluno.<br><br>
      <b>🧠 Lógica:</b><br>
      • Ler as duas notas de ponto flutuante <code>A</code> e <code>B</code>.<br>
      • Calcular a média ponderada sabendo que a nota <code>A</code> tem peso <b>3.5</b> e a nota <code>B</code> tem peso <b>7.5</b>. A soma dos pesos é <b>11.0</b>:<br>
      <code>MEDIA = ((A * 3.5) + (B * 7.5)) / 11.0</code><br>
      • Imprimir o resultado com a mensagem <code>MEDIA = </code> e o valor formatado com <b>5 casas decimais</b> após o ponto, seguido de uma quebra de linha <code>\n</code>.<br><br>
      <b>📤 Saída:</b><br>
      Imprima a mensagem <code>MEDIA = </code> seguida pelo valor da média do aluno com 5 casas decimais e uma quebra de linha.
    </td>
    <td valign="top">
      <b>📥 Input:</b><br>
      The input contains two double-precision floating-point values representing a student's grades.<br><br>
      <b>🧠 Logic:</b><br>
      • Read two floating-point numbers <code>A</code> and <code>B</code>.<br>
      • Calculate the weighted average considering grade <code>A</code> has a weight of <b>3.5</b> and grade <code>B</code> has a weight of <b>7.5</b>. The sum of weights is <b>11.0</b>:<br>
      <code>MEDIA = ((A * 3.5) + (B * 7.5)) / 11.0</code><br>
      • Print the message <code>MEDIA = </code> followed by the result formatted to <b>5 decimal places</b> and an end-of-line break <code>\n</code>.<br><br>
      <b>📤 Output:</b><br>
      Print the message <code>MEDIA = </code> followed by the student's average grade formatted with 5 decimal places and a newline.
    </td>
  </tr>
</table>

### 📥 Exemplo de Entrada / Example Input

```txt
5.0
7.1
```

### 📤 Exemplo de Saída / Example Output

```txt
MEDIA = 6.43182
```
