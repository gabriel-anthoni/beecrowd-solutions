  <tr>
    <td valign="top">
      <b>📥 Entrada:</b><br>
      A entrada contém quatro valores inteiros.<br><br>
      <b>🧠 Lógica:</b><br>
      • Ler quatro valores inteiros com <code>scanf()</code> nas variáveis <code>a</code>, <code>b</code>, <code>c</code> e <code>d</code>.<br>
      • Calcular a diferença do produto de <code>a</code> e <code>b</code> pelo produto de <code>c</code> e <code>d</code>:<br>
      <code>DIFERENCA = (a * b) - (c * d)</code><br>
      • Exibir o resultado formatado no padrão <code>DIFERENCA = X</code> com quebra de linha <code>\n</code> utilizando <code>printf()</code>.<br><br>
      <b>📤 Saída:</b><br>
      Imprima a mensagem <code>DIFERENCA = </code> seguida do valor calculado e de uma quebra de linha.
    </td>
    <td valign="top">
      <b>📥 Input:</b><br>
      The input file contains four integer values.<br><br>
      <b>🧠 Logic:</b><br>
      • Read four integer values using <code>scanf()</code> into variables <code>a</code>, <code>b</code>, <code>c</code>, and <code>d</code>.<br>
      • Calculate the difference between the product of <code>a</code> and <code>b</code> and the product of <code>c</code> and <code>d</code>:<br>
      <code>DIFERENCA = (a * b) - (c * d)</code><br>
      • Output the result formatted as <code>DIFERENCA = X</code> with a newline <code>\n</code> using <code>printf()</code>.<br><br>
      <b>📤 Output:</b><br>
      Print the message <code>DIFERENCA = </code> followed by the calculated value and a newline character.
    </td>
  </tr>
</table>
