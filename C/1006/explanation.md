#### 📥 Entrada:

- A entrada contém três valores de ponto flutuante de dupla precisão (`double`).

*Exemplo de entrada:*
```
5.0
6.0
7.0
```

---

<!----------------------------------------------------------------------------------------->

#### 🧠 Lógica:

- Leia três valores de ponto flutuante (`double`) através da função `scanf` e armazene-os nas variáveis `a`, `b` e `c`.
- Calcule a média ponderada sabendo que a primeira nota tem peso 2, a segunda nota tem peso 3 e a terceira nota tem peso 5 (soma dos pesos = 10):
  $$\text{MEDIA} = \frac{(a \times 2) + (b \times 3) + (c \times 5)}{10}$$
- Imprima o resultado formatado com 1 casa decimal no padrão `MEDIA = X.X`, garantindo a quebra de linha `\n` ao final.

---

<!----------------------------------------------------------------------------------------->

#### 📤 Saída:

- Imprima a mensagem `"MEDIA = "` seguida do valor da variável `media` com 1 casa após o ponto decimal e de uma quebra de linha.

*Exemplo de saída:*
```
MEDIA = 6.3
```

#### 📥 Input:

- The input file contains three double-precision floating-point values (`double`).

*Example Input:*
```
5.0
6.0
7.0
```

---

<!----------------------------------------------------------------------------------------->

#### 🧠 Logic:

- Read three double-precision floating-point numbers (`double`) using `scanf` and store them in variables `a`, `b`, and `c`.
- Calculate the weighted average considering that the first grade has a weight of 2, the second grade has a weight of 3, and the third grade has a weight of 5 (total weight = 10):
  $$\text{MEDIA} = \frac{(a \times 2) + (b \times 3) + (c \times 5)}{10}$$
- Print the result formatted with 1 decimal place as `MEDIA = X.X`, including a newline `\n` at the end.

---

<!----------------------------------------------------------------------------------------->

#### 📤 Output:

- Print the message `"MEDIA = "` followed by the calculated average formatted to 1 decimal place and a newline character.

*Example Output:*
```
MEDIA = 6.3
```
