      <b>🧠 Lógica:</b><br>
      • Ler o valor do raio <code>R</code> utilizando <code>scanf("%lf", &radius)</code>.<br>

      <code>A = 3.14159 * R * R</code><br>

      Imprima a mensagem <code>A=</code> seguida pelo valor da variável área, com 4 casas após o ponto decimal.
    </td>
    <td valign="top">
      <b>📥 Input:</b><br>
      The input contains a double-precision floating-point value (<code>double</code>), representing the radius of the circle.<br><br>
      <b>🧠 Logic:</b><br>
      • Read the radius value <code>R</code> using <code>scanf("%lf", &radius)</code>.<br>
      • Calculate the area of the circle using the formula:<br>
      <code>A = 3.14159 * R * R</code><br>
      • Output the result formatted as <code>A=X.XXXX</code>, with 4 decimal places and a newline <code>\n</code> using <code>printf()</code>.<br><br>
      <b>📤 Output:</b><br>
