      <b>🧠 Lógica:</b><br>
      • Leia o valor do raio através da função <code>input()</code> e converta-o para decimal (<code>float</code>).<br>

      • Calcule a área utilizando a fórmula matemática: <code>A = π · r²</code>.<br>
      • Utilize f-string para formatar a saída com exatamente 4 casas decimais.<br><br>

      O programa deve exibir o texto <code>A=</code> seguido pelo valor calculado da área com exatamente 4 casas decimais.

      <b>📥 Input:</b><br>
      The input contains a floating-point value (double precision) representing the radius of the circle.<br><br>
      <b>🧠 Logic:</b><br>
      • Read the radius value using the <code>input()</code> function and convert it to decimal (<code>float</code>).<br>
      • Set the constant value of <code>π = 3.14159</code>.<br>
      • Calculate the area using the mathematical formula: <code>A = π · r²</code>.<br>
      • Use f-string to format the output to exactly 4 decimal places.<br><br>
