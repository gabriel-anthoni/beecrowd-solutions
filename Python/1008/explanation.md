      <b>📥 Entrada:</b><br>
      A entrada contém dois valores inteiros (número do funcionário e horas trabalhadas) e um valor de ponto flutuante (valor recebido por hora).<br><br>
      <b>🧠 Lógica:</b><br>
      • Leia o número do funcionário e as horas trabalhadas usando a função <code>input()</code> convertida para <code>int()</code>.<br>
      • Leia o valor por hora usando a função <code>input()</code> convertida para <code>float()</code>.<br>
      • Calcule o salário multiplicando as horas trabalhadas pelo valor por hora: <code>SALARY = hoursWorked · salaryPerHour</code>.<br>
      • Utilize f-string para formatar a saída com quebra de linha e 2 casas decimais.<br><br>
      <b>📤 Saída:</b><br>
      O programa deve exibir o número do funcionário e o seu salário com exatamente duas casas decimais.

      <b>📥 Input:</b><br>
      The input contains two integer values (employee's number and worked hours) and one floating-point value (amount received per hour).<br><br>
      <b>🧠 Logic:</b><br>
      • Read the employee's number and worked hours using the <code>input()</code> function converted to <code>int()</code>.<br>
      • Read the hourly wage using the <code>input()</code> function converted to <code>float()</code>.<br>
      • Calculate the salary by multiplying the worked hours by the hourly rate: <code>SALARY = hoursWorked · salaryPerHour</code>.<br>
      • Use f-string to format the output with a newline and 2 decimal places.<br><br>
      <b>📤 Output:</b><br>
      The program must display the employee's number and their salary with exactly two decimal places.
